## 独立提示词结果

相同种子 `300100`、`300101`；每次重置场景与策略随机数；每条指令 300 步。
各配对初始头部图像的 SHA-256 一致。模型权重只加载一次。

| 条件 | 各种子最终结果 | 达到所请求目标 |
| --- | --- | --- |
| 发布标签：左电池放中间 | 左电池仍在左侧，未放到中间 | 0/2 |
| 同义改写：左电池移到中央 | 左电池仍在左侧，未放到中间 | 0/2 |
| 发布标签：右电池放中间 | 右电池仍在右侧，未放到中间 | 0/2 |
| 新目的：抓左电池并保持、不放下 | 最终电池在桌面，夹爪未保持抓持 | 0/2 |
| RMBench 原始整句（补充参照） | 未装配、仪表未通电 | 0/2 |

放置的判断结合最终图像与仿真诊断；抓持判断依据最终画面和电池高度，
没有将一次夹爪闭合记为成功。全部最终电池仍未满足官方 XY 对槽判据。
这里不把单电池子任务的“仪表未通电”当作失败原因。

**结论：当前接入尚未建立可靠的原句执行基线，不能据此证明“只因改写就失效”。**
提示词确实影响输出：相同初始条件下，同义改写相对发布左侧标签，第一动作块的
关节目标 RMSE 约为 0.166 / 0.359 rad（两个种子）。这只说明语言条件影响动作，
不证明语义遵循，更不等于泛化成功。

## 能力与证据边界

- 这是小样本开发试验，不是官方成功率复现或统计显著性结论。
- 模型只看到三路 RGB、关节状态、指令，以及当前头部图像填充的 keyframe。
  未启用历史关键帧检索；使用本项目网页现有 raster 渲染，训练视频外观与之有差异。
- 已核对 16/14 维映射、预处理参数、动作归一化统计及起始关节状态。
  严格加载不等于完整复现发布者的推理代码、视觉记忆和仿真时序。
- 原始 RMBench 整句是额外跨模型参照，不是这套子任务 π0.5 的受支持指令承诺。
  300 步预算的整任务结果也不能替代完整长任务评测。
- 仿真位姿/极性/成功诊断用于执行后的独立评价，不参与动作生成。
