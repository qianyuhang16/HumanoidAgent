# TCP：你对准点，程序算偏移

不再手填“5 cm 沿哪个轴”。程序用不同朝向的反馈自动求出 `link6 → 抓取点` 的 X/Y/Z。

## 启动

停止旧网页服务（Ctrl+C），从项目根目录运行：

```bash
.venv/bin/python -m primitive_vla_cobotmagic.calibration web
```

打开 http://127.0.0.1:18084，点 **右臂 TCP · 固定点标定 → 新建批次**。左臂有独立入口。相机内参和双臂外参不用重做；TCP 计算只用关节反馈、URDF 和同一点约束。画面用于辅助观察，不检测棋盘格。

## 你具体怎么做

1. **取下标定板，选定工具点。** 比如两指尖连线的中点。用固定小标记把中点标出来也可以。若用笔尖做标定，结果只代表笔尖，不会自动代表夹爪中点。
2. **夹爪开口固定。** 用本次想采用的开口，不必最大；整个批次不要改变开口、换工具或重新固定工具点。
3. **选一个固定参照点。** 把小十字/尖点固定在工作区。参照点坐标不用测量，只要它始终不动。不要拿在手里。
4. **第一次对准。** 用示教器让选定工具点与参照点重合。停约 2 秒，网页显示已停稳后，按空格记录。按键意味着你确认已经对准，程序不会从图像自动判定是否重合。
5. **换朝向，再对准原点。** 向前、向后、向左、向右倾斜；每次都把同一个工具点重新放回同一个参照点。不能只是移动位置，也不能只绕一个轴旋转。建议记录 6–8 组训练，最低 4 组。
6. **采验证姿态。** 再换 2–3 个未用过的朝向，重新对准后按 V。最低 2 组；这些姿态不参与计算偏移。
7. **点“求解并验证当前批次”。** 查看 `tcp_xyz_m`、偏移总长度和训练/验证最大点误差。默认二者都需 ≤15 mm。

网页内含叠加示意图和操作提示。空格/V 使用前点击网页空白处获得焦点，也可直接点采样按钮。工具朝向应在机械臂自然可达范围内变化，不要求到关节极限，也不要通过用力压住参照点来保持对准。

## 结果放在哪里

```text
workspace/cobotmagic-calibration/tcp/
  right-tool/runs/<批次>/result.json
  left-tool/runs/<批次>/result.json
```

每批保存原始图像、关节角、夹爪开口、时间戳、模型快照及校验值。重新求解会从关节角重新计算 FK。原有相机标定和示教悬停参考不会覆盖。

结果字段：

- `tcp_xyz_m`：相对所选臂 URDF 末端 `link6` 的偏移，单位米。X/Y/Z 的符号由求解得到，不需要猜。
- `tcp_rpy_rad: [0, 0, 0]`：**坐标轴约定**，TCP 坐标轴沿用 `link6` 坐标轴，不是额外求解出的抓取朝向。以后运动可继续采用你保存的示教朝向。
- `fixed_point_in_base_m`：同时估计的桌面固定点位置，不需要提前手测。
- `training_residuals` / `validation_residuals`：各姿态计算出的 TCP 相对同一个固定点的距离误差。验证姿态不改变已拟合 TCP。
- `gripper_position_m`：本批次采用的夹爪开口反馈，结果只对应这套工具几何。
- `accepted`：内部同点一致性通过；`physical_accuracy_verified: false` 表示没有独立实物精度证明。

网页显示结果但**不自动写入运动配置，也不执行移动**。下次生成移动脚本时使用对应机械臂、对应工具的通过结果。若选定的工具点本身不是真正抓取点，即使残差小也不能直接替代真正抓取点。

需要终端离线重新求解时，停止采集后运行：

```bash
.venv/bin/python -m primitive_vla_cobotmagic.calibration solve \
  --session workspace/cobotmagic-calibration/tcp/right-tool/runs/<批次>
```

## 拒绝采样/求解的提示

- 未停稳、反馈过期、时间戳不更新：等待新鲜反馈和停稳。
- 开口改变：恢复原开口；如果已改变工具几何，另开批次。
- 朝向太相似：改变朝向，再对准原固定点。
- 姿态变化不足：补充前后和左右倾斜；不能只转一个轴。
- 点误差过大：检查每次是否真的是同一个工具点对准同一个参照点、参照点是否移动、夹持是否松动，以及模型与反馈约定。

此 TCP 点误差阈值独立于手眼标定的 20 mm / 5°，不会混用。参考 URDF 范围提示仍只作为只读测量诊断，不修改运动控制限位。

参考：[固定点 TCP 示教方法](https://www.universal-robots.com/manuals/EN/HTML/SW5_22/Content/prod-usr-man/software/PolyScope/content/installation_g5/teaching_TCP_position.htm)。

TCP 最大点误差上限现为 15 mm。重启网页后可以继续原批次，重新求解使用当前阈值，旧 manifest 和原始样本保持不变；结果文件记录本次实际阈值。阈值变化时网页提示重新求解。放宽阈值不改变 TCP 拟合值和实测残差。
