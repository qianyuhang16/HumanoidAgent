该做什么

先做相机内参，再分别做左右臂外参。相机内参通过，不等于任何一条机械臂已标定完成。

  1. 标定板贴在平整硬板上，格长以实测值和当前配置为准；已打印的板无需因缩放重新打印。
  2. 内参：手持板覆盖画面不同位置、距离、倾角。手眼外参：板刚性固定到所选臂末端，使用示教器改变位置和朝向；相机固定不动。
  3. 每次移动后停约 2 秒，显示“可以记录”再按键。建议 20–30 组训练，另采 4–6 组独立验证；不能只平移或只绕一个轴旋转。
  4. 采完点击“求解并验证”。未通过时查看误差并检查数据；换夹持方式后新建批次，保留失败记录。

TCP 固定点标定 · 不需要填写偏移方向

全程保持：同一个工具点，对准同一个桌面固定点。改变的是机械臂朝向。

上图叠加显示三个不同时刻的朝向；橙色固定点始终不动，每次都让同一个工具点对准它。

  1. 选点：选定将来真正控制的抓取点，例如两指尖之间的中点。可以用固定小标记把中点标出来。若改用笔尖，对准并求出的就是笔尖 TCP，不会自动变成两指中点。
  2. 准备：把一个清楚的小十字或尖点固定在工作区。取下标定板，夹爪保持固定开口；不需要张到最大，也不需要相机内参。
  3. 对准并记录：用示教器让选定工具点与固定点重合，停约 2 秒，再按空格。程序只检查停稳，是否对准由你确认。
  4. 换朝向再对准：前后倾斜、左右倾斜，每次都把同一个工具点重新对准同一个固定点。建议 6–8 组训练，最低 4 组；不要只平移或只转一个轴。
  5. 独立验证：再换 2–3 个未用过的朝向，每次重新对准后按 V。验证姿态不参与求解。
  6. 点击求解：程序显示 TCP 的 X/Y/Z（米）、总长度和误差。默认训练及验证最大点误差均需 ≤15 mm；姿态不足、开口改变、误差过大都会提示。

结果的工具坐标轴约定与 URDF 末端一致，程序自动输出 tcp_rpy_rad: [0, 0, 0]；无需你猜 XYZ 偏移方向。TCP 位置由采样求解，抓取朝向可以继续使用已保存的示教朝向。仅对本批次选定的工具点和开口有效。

时间差上限由配置控制（当前默认 400 ms），数据年龄上限 0.5 秒，外参采样保留停稳检查。退出服务：终端 Ctrl+C。多窗口切换批次会使旧窗口操作失效。
