# 025：设备动作队列与调度

ToolDefinition 增加可选 device_id；同设备的动作共享控制资源，旧工具保留原有行为。
ActionQueue 提供异步提交、任务快照、修订等待和取消；每设备按提交顺序执行，不同设备
无共享资源时并行。共享资源按提交顺序仲裁，直接调用不能绕过已有队列。

实际执行仍经过 ExecutionManager 的参数、禁止工具、实时前提、期限、去重和停止检查。
排队取消不派发；运行中取消等待停止确认，未确认保留控制锁。关闭时先撤销待执行任务，
再停止活动任务，结果通过注入入口发布。保留原有全局控制锁，本提交不实现故障隔离。

验证：新增队列回归覆盖设备串行／并行、共享资源、直接调用越序、取消、关闭、去重、
派发前重新检查前提和版本等待。测试替身仅位于 tests；下一提交装配 Agent 工具入口。
