# 022：参考资料与实时观测的有效期

Observation.lifetime 默认为 scene，保持动作派发后失效；adapter 可将静态地图、标定
等资料标为 reference，跨动作复用。两者均支持 ttl_s；新版本同源观测会使旧版本及依赖
它的判断失效。恢复快照仍标记 historical，不自动恢复设备状态。

派生判断跟随证据有效性。结合旧地图和新定位时，以动态测量确定测量时间，仍保留并检查
地图依赖，不把地图发布时间当作新位姿的采集时间，也不将旧位姿刷新成新位姿。
严格目标策略对动态证据应用 max_age_s；参考资料按自身 TTL 和替代版本检查。
单独地图、它的图片别名和仅从参考资料派生的多层判断都不能证明当前目标完成。

验证覆盖跨动作地图复用、动态证据失效、旧地图＋新定位验收、参考资料过期／缺时间／
换版本导致判断失效，以及历史恢复。原有桌面抓取与验证测试保持通过。
