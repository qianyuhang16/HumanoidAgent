# 008 — 闭环证据有效性检查

补齐跨模块检查：相同传感器的新帧使旧判断失效；晚返回的旧判断不能推翻新证据。
严格验证递归检查引用链，不能将预测经另一层推断包装成已观测事实。
可用 subject_arguments 把工具的对象参数绑定到目标对象，防止杯子的验收被用于碗的动作。

工具返回的状态贡献在执行入口校验，错误作为反馈返回且不产生部分状态；
最终回答支持已登记观测和判断引用。状态快照拒绝未知版本，后台估计也遵守调用期限。
修正异步动作在期限边缘自行撤销时的竞态：记录为工具超时并确认停止，不误作整轮任务取消。

验证：新增运行时端到端测试，验证过早完成被拒绝、补充观测后主 Agent 可在同轮提交判断
并完成；补充新帧、间接预测、对象错配、坏返回值与乱序结果回归用例。
