# 002 — 从会话中分离状态记录

新增 StateJournal，拥有动作结果、观测、环境判断、图像引用及验证记录。
Session 保留对话事件和工作摘要，通过兼容属性读取状态；快照同时保存可恢复的状态历史，
旧快照仍可导入。恢复的证据一律标为历史，不恢复控制句柄。

主 Agent 可在正常回复中提交 claims，系统校验完整批次后采纳；来源由运行系统赋予。
查询视图按观测时间处理乱序，同源新记录替换旧视图，异源冲突保留双方。
缺失采集时间为 unknown；动作失效、TTL 和恢复不会删除历史。

验证：新增状态记录测试覆盖乱序、冲突、过期、失效、原子校验和新旧快照读取；
结合核心回归测试验证主循环、两种验证模式和模型传输兼容性。
动作触发失效及按需状态查询将在后续执行／能力接入提交中连接。
