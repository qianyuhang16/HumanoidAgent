# 006 — Cobotmagic 接入统一契约

相机工具和 Agent 相机使用真实帧 timestamp_ns 填写采集时间；分割／深度复用原观测，
不会把推理返回时间当作采集时间。记录层允许相同内容的观测引用复用，拒绝同 ID 改写。
兼容图像标签关联到真实观测，因此原有前后图和新契约共用证据时效。

检测输出映射到 detection.v1，明确像素坐标和所属图像；支持检测框或已有目标像素。
对象引用仍是本次检测 token，不冒充跨帧对象跟踪。深度预测保留原输出，不推断实测位置或持物。
IK、复位和 VLA 显式返回执行阶段与控制释放状态，VLA 预算结束不转换为任务完成。
VLA worker 没有提供采集时间的旧图片仍为 unknown，严格验收需另取带时间戳观测。

验证：新增真实扩展接口的离线测试，覆盖显式／隐式采集、证据复用和语义保留；
结合 Cobotmagic 现有回归测试检查 IK、运动、恢复、感知和 VLA 兼容性。不连接真实设备。
