# 015：验证多模态证据的完整链路

独立 JSON reviewer 的提示明确：URI 是资源描述，不等于已读取内容；内置传输只渲染图片。
缺少可用模态、null 元数据或 partial 状态不能被默认解释为目标已完成。
支持点云或其他模态的验证方法可以通过原有 reviewer adapter 接口接入。

新增跨模块测试，从混合观测进入 Session，经过 Verification 到 JSON reviewer，
检查点云及 null 元数据完整保留在证据中，只有图片进入图像通道。
同一模拟满意判断在有采集时间时可被采纳，缺少采集时间时仍被严格策略拒绝。
测试只验证路由和契约，模型客户端使用 fixture，不声称验证了感知准确性。
