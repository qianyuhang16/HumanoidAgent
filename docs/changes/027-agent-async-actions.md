# 027：Agent 异步动作入口与会话生命周期

为声明 device_id 的动作装配 execution.submit/query/wait/cancel。提交即时返回独立任务 ID，
原动作结果以该 ID 进入状态记录和会话，验证器仍按原动作定义处理。提交回执不作为物理
完成证据。重复同一提交调用去重；实际参数在入队和派发两处验证。

模型上下文加入活动／近期任务和队列 revision，使用有界 wait 等待变化。每台设备队列
由 adapter 的设备身份决定，模型不能伪造设备归属。旧同步调用继续可用。

存在排队或运行任务时拒绝 completed；其他结束、预算耗尽、超时和用户取消都会撤销
等待任务并确认活动任务停止。结果记录在报告生成前完成。快照保存任务与参数，恢复后
标记 historical/interrupted，不自动重放机器人动作。

验证：端到端覆盖 A 运行期间提交 B、B 先完成并独立评估、再等待 A；提前完成被拒绝；
非法提交、查询、去重、取消、结束清理、期限、控制未知和历史恢复均通过。
测试 provider/model/reviewer 仅位于 tests/integration/test_async_agent.py。

边界：控制锁、场景失效与严格目标策略仍是全局范围；队列不跨服务重启恢复执行；
不包含联合搬运、优先级重排或运行中用户追加目标。
