# 619 单人首测任务说明

钱玉航负责现场首测，滕飞、陈梓昕、李佳晋异步复核。候选为干燥桌面抓碗，日期未定，803 旧双臂夹爪模型与 619 末端、相机的适配尚待确认。先运行 SOP 中的离线入口，再按现场已有真实入口决定是否启动。

首轮先争取拿到一份能复核的抓碗调用记录。首次失败也可以交回，缺少启动条件时交回具体卡点。若修正了明确问题，或希望确认相同条件下能否复现，按 SOP 判断是否人工复测。每次调用单独留档，保留首次结果。

本包演练TaskAwareAgent、对象绑定、任务Memory、同次调用/观测与终态门，以及陈分支“两件物体入同一容器”的合成合同。离线通过只证明工程接点；陈host.build为synthetic-only，application.py默认普通Agent。真实Profile/Provider、抓碗模型入口和硬件未随包提供，不能将合成入口改名当实机入口。

现场只记录实际发生的路径：①Agent派发，保留Agent入口及其派发记录；②专家单测，由现场入口直接启动专家；③未启动，记录缺项。专家单测不能写成Agent闭环。

目标是确认实际入口能否调用、怎样结束、碗的同次可见终态。启动前写明技能支持的真实终点，抓起不等于入盒。time budget到期只表示退出；没有足够观测则记unknown/uncertain，不推断成功。此次不要求旧人工放块采集、故意放偏、倒水或完整两物入盒链。

每次调用回传一份填好的 `return_template.json`，附脱敏的同次请求、返回和前后观测。分别写清专家为何退出、机器人实际是否已停，以及判断停机状态的依据。若由 Agent 派发，依次记录调用前状态、刚收到返回时的状态、实际选的下一步，以及本次记录截止时的任务状态和日志位置。截止时仍在等待就填等待。专家单测和未启动时，Agent 状态与决策填“不适用”。
